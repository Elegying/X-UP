# X-UP

面向 X（原 Twitter）的 LSPosed 模块，使用现代 Xposed API 102。当前开发版：1.8.0-beta8。

## 功能

- 保留 X 原有右侧双击快进，新增下半区双击；双击后连续点按沿用 X 原生累加提示，可选每次 5 / 10 秒。
- 全屏视频左右滑动调整进度，长按临时 2 倍速，松手恢复。
- 全屏下载图标保存视频到系统相册；下载中可点击图标查看或取消，通知关闭时也可在模块下载设置页取消。
- 帖子评论默认按最新回复显示。
- 默认开启去广告：过滤统一时间线中的推广帖、推广用户、推广趋势与图片广告，可独立关闭。
- 三种本地引擎可选：Google ML Kit（默认）、腾讯 HY-MT2、OPUS-MT。一次只运行所选引擎，X 原生自动翻译为互斥的联网备用。
- 本地中文翻译：英语、日语、帖子、评论、引用及可识别的简介和私信文字；腾讯引擎可参考已加载的直接上级内容。
- 用户名、昵称与 @账号保留原文，简介和正文仍按所选引擎翻译。
- 模块 → 检查更新：检查 GitHub 版本、选择是否接收测试版、后台下载、校验并启动系统安装。
- 每项功能独立开关，设置通过 LSPosed 服务同步。

## 安装与模型

需要 Android 11 或更新版本、Root、兼容 API 102 的 LSPosed。当前 Hook 适配基于 X 12.31.0-prod.01，其他 X 版本需要重新验证。

1. 安装 Release APK，在 LSPosed 启用 X-UP，作用域选择 X，然后重新启动 X。
2. 打开“翻译方式”，再点击“下载所选模型”。新安装或没有有效引擎设置时默认使用 Google ML Kit；下载完成前保留原文，也可手动选择其他引擎。
3. 下载后点击“测试英语与日语”，再到 X 中检查。
4. 关闭本地翻译会切换到 X 原生联网备用；重新开启本地会关闭原生，缺少模型时提示下载，可选择稍后。已下载模型始终保留。

正常覆盖安装保留已保存的引擎选择和已下载模型，切换引擎也不会删除其他模型。已有用户如需使用 Google，可在“翻译方式”中切换一次。请直接安装新版 APK；卸载或清除应用数据会删除模型。

| 引擎 | 在线下载 | 取舍 |
| --- | --- | --- |
| Google ML Kit（默认） | Google SDK 管理中文和日语语言包，官方约每包 30 MB | 轻量，不支持帖子上下文提示词，日译中经英语中转；需要 Google 下载服务可达 |
| 腾讯 HY-MT2 | 461.86 MB，腾讯官方 ModelScope / Hugging Face | 可使用帖子上下文，运行内存与耗时较高 |
| OPUS-MT INT8 | 135.81 MB 压缩包，解包约 163.42 MB，项目 Release | 英译中直译，日译中经英语中转；短句速度优先，复杂语气易失真 |

三个引擎的模型均不打包进 APK。500 MB 限制为单个引擎模型大小，全部下载的合计空间会超过 500 MB。ML Kit 不提供精确下载百分比及暂停接口；腾讯与 OPUS 支持校验、断点续传。

腾讯模型为官方 **Hy-MT2-1.8B-1.25Bit-GGUF**，文件 **461,860,800 字节（461.86 MB / 440.46 MiB）**，严格小于 500 MB。模型不包含在 APK 中；主要的本地模式不需要 API Key，只有首次下载需要联网。备用的 X 原生翻译需要网络。

下载地址固定到腾讯官方 ModelScope 仓库（失败后尝试腾讯官方 Hugging Face）的指定版本，支持暂停续传，完整文件通过大小及 SHA-256 校验后才启用。不强制 Wi-Fi：移动流量或系统标记的计费网络会先提醒剩余下载量，由用户确认继续。官方渠道已在开发电脑完成下载校验，不代表所有地区或用户网络均可访问；下载失败时保留已下载部分并提供重试。

- [腾讯官方国内模型页](https://modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-1.8B-1.25Bit-GGUF)
- [腾讯官方模型页](https://huggingface.co/tencent/Hy-MT2-1.8B-1.25Bit-GGUF)
- ModelScope 版本：`a1ba5a8101d7b257d42c0980e0d6415d0bd9e1cf`
- Hugging Face 版本：`9df5c824a00a744fb0512a29c640466f4d97dfb0`
- SHA-256：`cc497fe8f033b52b3b8b00a7669e9661435432f9d4cd43f7ed24400c01507a93`

两种翻译使用同一个模式值保存，无法同时启用。切换本地模式时，插件不会自动调用 X/Grok 在线翻译；切回原生时停止本地文字翻译。原生模式覆盖范围由 X 决定，不承诺自动翻译个人简介和私信。原自定义大模型接口、API Key、模型名称和连接测试均已移除，升级会清理旧接口凭据。

## 在线更新

从“模块 → 检查更新”进入后检查项目 GitHub Releases；支持手动重试与测试版渠道开关，不做后台定时联网。下载使用 Android 系统下载管理器，可离开页面后继续并显示进度；移动计费网络先提醒，支持取消与失败重试。

只有高于当前版本、同包名、同签名且 SHA-256 匹配发布附件的 APK 才能交给系统安装器；不会自动降级或静默安装。首次安装需按系统提示允许 X-UP 安装应用。正常覆盖安装保留模型与设置，完成后重启 X。取消系统安装后可回到更新页重试。网络受限时提供 GitHub 发布页入口。

## 去广告范围

“阅读与翻译 → 去广告”开关实时同步，以明确广告元数据识别，不根据正文关键词删除内容。过滤统一 URT 列表及其模块内广告，只复制界面列表，不修改 X 原始模型；关闭可恢复保留的原始内容。推荐关注、普通趋势、引用内容和分页条目不因广告关键词被误删。

不拦截网络请求；视频贴片、独立广告页面与不走统一时间线的特殊广告尚未覆盖。当前仅适配 X 12.31.0-prod.01，实际界面重绘与分页仍待实机验证。

## 性能与边界

X 前台异步预热所选引擎，后台停止新翻译并取消已失去订阅者的任务。保留模型 **2 分钟**，期间返回复用，超时空闲释放；已下载文件保留。意外退出通过心跳过期检测回收，Android 也可能因内存压力提前回收进程。ML Kit 不能中断 SDK 正在执行的单句，取消后不继续后续句或应用结果。

使用单个所选引擎、重复请求合并、内存译文缓存、最多 8 个任务的队列、过期任务丢弃。客户端空闲名额直接接续仍可见的排队任务，完成结果只通知相关文字，周期刷新跳过已完成内容。腾讯使用短提示词，另两种专用模型使用分句与标记保护，不能通过拼接提示词获得大模型式上下文理解。ARM64 根据 CPU 能力选择 STQ 点积加速，并保留普通 ARM 路径。模型文件体积不等于运行内存，加载还需要额外内存。

小模型逐句选择英语或日语；中文夹字母、其他文字脚本，以及没有假名的汉字混合句保留原文，避免误走英语模型。表情、组合表情与旗帜绕过小模型原样保留。未知字符和只有标点的异常输出不会进入成功缓存；英语句子不再因另一句含日语而多走一次日译英。此策略偏向保留内容，不能替代完整语言识别，也不扩展模型支持的语种。

首次加载、长文本和上下文都会影响延迟；不承诺所有帖子两秒内完成。量化模型仍可能误译俚语、反讽和省略表达；推理异常、超时或富文本标记不完整时保留原文。图片文字、输入框及部分特殊自绘页面不处理。译文缓存在内存中，不将帖子或私信写入日志或上传翻译服务。

## 从源码构建

需要 JDK 17+、Android SDK 36 / Build Tools 36.0.0、NDK 28.2.13676358、CMake 3.22.1。

```sh
./scripts/prepare-native.sh
python3 scripts/prepare-opus-native.py
bash test.sh
./gradlew testDebugUnitTest lintRelease assembleDebug
```

构建使用 Java 17 字节码级别，与 libxposed API 102 依赖对齐。`test.sh` 包含下载鉴权、任务恢复、取消清理、手势入口、Google 模型状态回调，以及设置保存到翻译任务取消和重连同步的主机回归；JUnit 覆盖模型暂停续传等文件传输边界。Android 与 SDK 替身测试不能代替实机验证。对应 GitHub Actions 配置见 `.github/workflows/android.yml`。

发布构建需要自行提供签名私钥并调整 `signingConfigs`。项目不提供私钥，用户自行构建的 APK 无法覆盖使用另一密钥签名的版本。

原生源码固定到 llama.cpp PR 22836 的 `1e411d8f5a1e23525fa3265dfb4bd76265465397`，下载校验后应用项目补丁。权重编号兼容与点积运行时分发补丁见 `native/patches`。不会在构建阶段下载模型。

OPUS 依赖的固定提交见 `scripts/opus-native-lock.json`，Android 兼容补丁见 `native/patches/ct2-android.patch`。模型来源、摘要及转换环境见 `docs/opus-model-provenance.json`；转换脚本为 `scripts/export-opus.py --output <目录>`。转换环境：CTranslate2 4.8.1、Transformers 4.57.6、SentencePiece 0.2.1、sacremoses 0.1.1、PyTorch 2.13.0；转换需要额外下载原始权重。固定源版本与环境可复现转换流程，ZIP 时间戳可能使压缩包摘要不同。

本轮完成腾讯与 OPUS 的电脑端真实模型推理和自动化验证；ML Kit 完成依赖解析、Android 编译，未在 Android 上运行 SDK 或验证其模型下载。未操作实体手机，不代表全部 X 页面、内存峰值和翻译延迟验收通过。基础引擎审查见 `docs/1.8.0-beta2-review.md`；本次手势与调度变更见 `docs/1.8.0-beta3-review.md`。
