# X-UP 1.8.0-beta1 审查记录

日期：2026-10-08。版本号 20，LSPosed API 102。此版为供用户自行实机测试的测试版，未连接或操作手机。

## 结论与未通过项

已生成签名 APK，已完成源码检查、自动化测试、电脑端真实模型推理，以及实际下载代码对官方模型的完整下载校验。

**不能据此宣布所有翻译质量合格或打开帖子两秒内完成。** 反讽样例“Yeah, that aged well.”即使提供预测失败、实际成功的上下文，仍可能被译成正面语气。量化模型在俚语、反讽和省略表达上存在边界；此项明确保留为质量限制。

本轮没有 Android 真机的加载时间、耗电、内存峰值、X 全页面覆盖、全屏下载和手势实测。之前版本的设备记录不能替代本版验收。

## 最终产品规则

- 腾讯本地翻译为默认主模式。X 原生自动翻译为联网备用，两者使用一个 `translation_mode` 值持久化、同步，避免同时开启。
- 关闭本地翻译会切到原生备用；重新开启本地会关闭原生。关闭原生也会切回本地。
- 切回本地但没有模型时提示下载，允许稍后；模型完成前保留原文。单次翻译失败不会暗中启用在线翻译。
- 模型独立下载，不放进 APK。移动数据和系统标记的计费网络会提醒预计剩余下载量，用户确认后继续；不强制 Wi-Fi。
- 保留翻译总开关与上下文开关；各视频功能和最新回复设置沿用现有独立开关。

## 修复与性能处理

1. 删除自定义大模型接口、API Key、模型名称与连接测试页面及远程服务实现；升级清理旧配置与 Android Keystore 密钥，不读取或输出密钥。
2. 改为单个手机本地推理引擎，通过已校验的文件 mmap 加载；单工作线程复用模型，避免多个模型实例挤占内存。
3. 英语、日语共用一份模型。整段文本请求携带已加载的直接上级或引用上下文，不逐词翻译、不额外抓取整条讨论串。
4. 合并重复请求，译文按文本、上下文和模型版本缓存；缓存只在内存，正文不写入日志。后台不派发新的显示请求，排队数量和等待时间有限。
5. 原生对接保留模型要求的起始 token，修复通用聊天模板漏掉起始标记导致的乱码。
6. GGUF 兼容补丁只识别固定架构、模型名与旧量化编号组合；保留官方权重原文件和原摘要，不自行改写权重。
7. STQ 使用 ARM NEON；具备点积指令时走独立编译的 dotprod 函数，不支持时保留基础路径。只给加速函数开启高版本指令集，避免整个模块要求新 CPU。
8. 修正富文本约束提示的位置，避免模型把提示本身当作待译文本。保留网址、账号与格式锚点；输出缺失、重复或顺序错误时保留原文。
9. 下载固定文件大小和摘要，支持 200 重下、206 严格范围检查、断点续传和原子替换。中断保留临时文件，校验不通过不会作为模型启用。
10. 模型就绪通过设置服务发布版本，使 X 清理旧失败状态。翻译开关变化后丢弃旧请求结果，不让晚到结果覆盖新模式。

## 用户实测重点

1. 首次下载、使用流量确认、暂停续传、下载后自测。
2. 本地/原生互斥切换及翻译总开关；切换后旧结果不得覆盖当前模式。
3. 英语、日语帖子、短评论、长评论、引用、简介和私信；观察首译与重复查看耗时。
4. 复杂反讽请对照原文，不能仅依据本地译文判断作者态度。
5. 原右侧双击、下半区双击、5/10 秒、滑动进度、长按恢复、全屏下载进度与相册保存。
