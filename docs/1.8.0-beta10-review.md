# X-UP 1.8.0-beta10 修复与实机验收

2026-10-12；版本号 29；现代 Xposed API 102。本记录对应本地签名构建及手机覆盖安装，不代表已发布 GitHub Release。

## 插件失效原因

beta9 只允许 X `12.31.0-prod.01` / `312310001` 安装 Hook。手机升级到 `12.33.1-prod.01` / `312331001` 后，日志明确记录“未适配的 X 版本，保持原行为”，导致整个模块跳过加载。

本版移除版本号拦截，使用 DexKit 按业务字符串、参数类型、字段语义及调用关系识别入口。目标 APK 的版本、路径、文件大小、修改时间、分包，以及模块版本和缓存规则共同决定缓存是否有效。初始化完成后关闭扫描器，运行期间复用已确认的反射入口。

10 项能力独立校验和安装，单项异常会撤销该项已安装的 Hook。缺失或出现多个候选时保留 X 原行为，状态页显示结果；文字翻译还要求身份文字保护先成功，避免误译昵称和账号。兼容状态接口只接受模块自身或 X 的 UID，限制字段和版本，不提供文件与历史状态查询。

适配过程覆盖混淆改名、Compose 可选参数增加、回复排序入口迁移、Kotlin Lazy 缓存字段区分、布局尺寸类型关系。旧版与新版 APK 均完成静态结构检查。小版本更新在这些结构契约仍成立时可以自行匹配；业务重构或候选歧义仍可能需要更新模块，不能保证全部未来版本兼容。

## 三个引擎的下载修复

| 路径 | 已确认的问题 | 修复与验证 |
| --- | --- | --- |
| 腾讯 / OPUS 共用传输 | 合法的短分段 HTTP 206 被误判为失败；完整分片仍要求重复预留下载空间 | 连续读取受校验的范围响应；已完整分片可直接校验；暂停、416 和失败时保留进度；限制分段次数并保留大小、SHA-256 校验 |
| Google 下载服务 | 服务销毁后仍占用全局下载状态，影响其他引擎；服务重建未接续 SDK 完成通知；旧回调能覆盖新任务状态 | 管理 SDK 任务观察者，按任务归属释放状态和接收完成回调；回归覆盖旧实现失败、新实现通过 |
| Google 状态说明 | SDK 错误和系统等待流量确认容易被当作网络失败 | 显示具体语言与错误原因；下载期间提供系统下载管理入口，说明中文、日语任务可能分别需要确认 |

没有修改模型来源、固定版本、摘要或 TLS 校验，也没有添加无界自动重试。

- 腾讯：以生产 `ModelTransfer` 从 ModelScope 完整下载 461,860,800 字节；另一次暂停后从 Hugging Face 续传，两次均匹配固定 SHA-256 `cc497fe8f033b52b3b8b00a7669e9661435432f9d4cd43f7ed24400c01507a93`。
- OPUS：生产传输完成 135,806,124 字节下载，匹配固定 SHA-256 `7362cbd5bbfa3a38bed1a1b97c34412636cb2da4dd62d1e95335068443d4194a`，生产安装逻辑校验全部 10 个清单文件。
- Google：Android 17 手机中，两个全新语言包任务曾同时处于系统等待 WLAN 状态，下载量为零。分别确认系统流量提示后成功下载中文、日语包，并完成英日样例翻译。该首次下载证据来自 beta9 的相同 ML Kit SDK；beta10 服务生命周期修复另有失败前后对照回归，最终包也复测了已下载模型。

Google 首次下载试验前完整备份，结束后恢复原有模型和 SDK 配置，69 个原文件逐个 SHA-256 一致，恢复后样例翻译成功。三个引擎的原模型和用户原先的 Google 选择均保留。本次未从当前公开下载源复现反馈者的原始错误，不能将所有用户失败归结为同一个原因。

## 最终构建与手机结果

- `bash test.sh`：872 项主机断言通过。
- `testDebugUnitTest`：124 项 JUnit，失败、错误、跳过均为 0。
- `lintRelease`：0 错误、43 警告；警告未清零。
- `assembleRelease`：签名通用 APK，ARM64 与 x86_64，16 KB ZIP 对齐通过；签名与 beta9 相同，可覆盖安装。
- 最终 APK：64,698,872 字节，SHA-256 `5879e032b6caa0d29d0dd8a87ccc790b0735df48b47dab8a1e85a86120ae0d94`。手机安装文件摘要与交付文件一致。
- Android 17 / X 12.33.1：10 项能力全部加载成功，状态页显示当前版本和逐项结果；本次冷启动记录为 815 毫秒，不作为普遍性能承诺。
- 最终包中，暂停视频左下区域双击显示原生 `+5s`，剩余时间从 52 秒变为 47 秒；双击后继续点按显示累计 `+10 秒`，47 秒变为 37 秒，暂停状态保持。
- 全屏滑动跳转已在同轮候选包实测：暂停状态下从 2,595 毫秒跳至 8,513 毫秒，未自动恢复播放；最终包保留该实现。
- 最终包完成视频保存，系统相册识别文件为 87,672,252 字节、55.68 秒、3840 × 2160。验收后仅移除本次新建的视频，原视频保留。
- 本地简介翻译完成开关前后对照，关闭时恢复英语，开启时显示中文，`SpaceX` 和 `@SpaceX` 保留。最终包复验简介翻译及三个引擎“已下载”状态，原 Google 引擎选择保持。

加载成功并不等于每项行为已完成独立验收。当前手机同时启用其他 X 模块，本轮不能将广告消失单独归因于 X-UP；全部页面、回复排序效果、长按倍速、不同机型、长时间稳定性和翻译质量仍未完整覆盖。

本地详细日志、APK 检查与设备试验记录位于被 Git 忽略的 `build/reports/adaptive-2026-10-12/` 和 `build/reports/model-download-diagnosis/`。其中原应用数据备份仅用于恢复，不进入源码或公开附件。
