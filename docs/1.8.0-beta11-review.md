# X-UP 1.8.0-beta11 修复与发布验证

2026-10-19；版本号 30；目标 X 12.35.0-prod.01（312350001）；Android 17 实机。本版按测试版渠道发布。功能修复包已同签名覆盖安装；发布前最后增加 HyperOS 说明文案，设备已断开，最终文案包未再次覆盖安装。

## 修复内容

- 下半区域快进：兼容 X 新版尺寸回调构造函数的 byte 参数，同时保留旧版 int 参数；继续使用调用关系、共享手势状态和唯一候选约束。
- 时间线去广告：兼容 Compose 入口尾部两种标记参数布局，动态定位 Composer 与 flags。
- 原生翻译及帖子翻译桥接：兼容新增构造参数及参数顺序；当目标要求具体协程作用域时，使用原 CoroutineContext 构建包装，保留 Job 和取消关系。
- 兼容状态回传：检查实际保存结果，启动后有限重试；失败轮次结束后冷却 60 秒，后续 Activity 恢复时允许重新尝试。成功后停止回传，不增加永久定时任务。
- 模型测试：切换引擎时取消旧测试、清除旧结果，并在状态与结果中标注引擎，丢弃迟到回调。
- 更新目标缓存版本，防止旧解析结果继续命中；状态页增加系统后台限制下的恢复说明。

## 验证边界

10/10 表示各功能目标成功解析和 Hook 安装，不等于所有真实业务场景均完整验收。原生翻译页面出现译文，但已有缓存和其他模块可能参与，尚未独立归因一次全新自动翻译请求；去广告尚缺稳定广告样本的开关对照。10 秒档、长时间播放、全部视频格式与不同网络条件未在最终包上逐项复测。

HyperOS 曾拒绝 X 访问模块 provider。此次增加的是兼容状态回传恢复和操作指引，不能绕过系统后台限制，也不能据此声称所有翻译及下载服务冷启动问题已根治。模型本身的翻译质量未改变。

REA CLI 的包检查因缺少 `REA_JADX_MCP_JAR` 未执行成功；APK 结构分析使用已有 JADX 和本地 DEX 扫描，未将其标记为 REA 引擎证据。
