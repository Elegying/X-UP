# X-UP 1.8.0-beta12 / X 12.42 实机适配记录

2026-11-14；版本号 31；设备 Xiaomi 17 Pro Max、Android 17 / API 37；LSPosed 2.2.1 (7912)、API 102。目标为 USB 手机实际安装的 X 12.42.0-prod.01（312420001）。源码基线 `0d4079b`。本次仅本地构建及设备安装，未推送源码、创建标签或发布 GitHub Release。

## 问题与修复

原 beta11 在该设备仅加载 6/10 项能力。四处失败均由实际 APK 结构确认：

- 下半区双击：连续点按回调被 R8 合并，旧的 `(float, Function1, Function0, state)` 构造器不存在。改为查找已验证手势组合入口调用的构造器，并核对实际参数中唯一的状态、操作与回退函数，避免作用于同类其他合并分支。
- 去广告：统一时间线列表由第 0 个参数移到 Lazy 之后的第 1 个参数，尾部仅一个 Compose 标记。验证列表、枚举及两个布尔参数序列，动态定位列表及其 dirty bits；旧版两/三个标记仍保留。
- 最新回复：评论仓库构造器由 6 参数扩为 7 参数，新增尾部 boolean；继续要求 long ID 和排序枚举处于已知位置。
- 视频下载与手势：图库旧特征开关字符串已删除。新增图库组合业务特征匹配，并继续检查唯一候选、生命周期及状态枚举，保留旧匹配路径。

未用固定混淆类名或简单版本放行替代结构检查。未改动 X APK。
