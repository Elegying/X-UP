# X-UP 1.8.0-beta2 审查记录

日期：2026-10-08。版本号 21，LSPosed API 102，Android 11+。本轮未连接或操作实体手机。

## 实现

- 引擎接口隔离腾讯、ML Kit 与 OPUS；设置固定 ID，单选互斥，仅所选引擎参与翻译。保留腾讯默认和 X 原生联网备用。
- 腾讯保留上下文提示及 ARM STQ 运行时加速；ML Kit 使用官方离线 SDK；OPUS 使用固定版本 CTranslate2 INT8、SentencePiece，英语直接译中，日语经英语中转。
- 小模型按句处理，保护链接、账号锚点与换行；分句缓存 256 条。专用模型没有被伪装成能理解上下文的大模型。
- 单工作线程、最多 8 个任务、相同请求合并、引擎与模型版本隔离缓存；取消仅影响对应调用者订阅，全部订阅取消才中止任务；切换后旧结果丢弃。
- X 前台异步打开所选引擎。后台停止新翻译、取消旧页面订阅，内存保留 **120,000 ms**；返回复用；到期空闲关闭。意外退出通过 20 秒心跳过期检测，随后执行两分钟回收。Android 可能提前回收进程。
- 不用永久 dataSync 前台服务维持翻译，改为受 X 生命周期控制的绑定。模型及视频下载仍使用相应前台服务。
- ML Kit 的单句 SDK 任务不能强行中止；取消会阻止后续句和结果应用。SDK 超时与关闭后的内部资源释放由 SDK 决定。
- 腾讯和 OPUS 的固定来源、大小和 SHA-256 校验，OPUS 逐文件白名单和摘要校验。Google 模型由 SDK 管理，不伪造下载百分比或暂停能力。
- 移动流量下载需提醒，不强制 Wi-Fi。保留所有已下载模型；未修改旧 ModelFiles 的文件路径、校验字段与模型摘要。
- 正常覆盖安装保留数据；卸载和清除应用数据不在保留范围内。三个模型的 500 MB 限制按单引擎计，全部下载总空间大于 500 MB。

## 验证结果

- 核心回归 386 个断言通过，含原视频/手势回归与新增引擎缓存、旧结果丢弃、请求取消。
- 服务生命周期测试运行生产 LocalTranslationService：19 个断言已包含在上述总数；验证 119,999 ms 未释放、120,000 ms 释放、提前返回复用、取消隔离、去重、切换及关闭。
- JVM 单元测试 42 项通过，含真实 ModelBundle 解包成功、路径穿越拒绝、错误摘要、大小限制、取消，以及小模型分句/锚点保护。
- assembleRelease / testDebugUnitTest / lintRelease 通过。Lint 为 0 错误、32 警告，包含同步设置写入、需导出的桥接组件、应用上下文静态持有、UI 与工具版本建议。未批量抑制警告。
- STQ 内核 32 组随机标量/运行时分发/参考点积比较通过。腾讯与 OPUS 原生过期取消票据均拒绝继续推理。
- OPUS GitHub 公开模型包匿名下载完整 SHA-256 匹配；生产 ModelTransfer 校验、ModelBundle 十个文件解包校验通过；解包后的真实模型可完成英日推理。
- APK 包名保持 io.github.jared.xlowerseek，旧签名证书 SHA-256 为 3f3e9f2d2b12b19feb8265fb9610cb02a4414a73b9db9a0d1c48ed8c4351734b；新签名相同。所有原生库 LOAD 对齐为 16 KB，APK 16 KB ZIP 对齐通过，包内没有 GGUF、SPM 或 model.bin 权重。

## 桌面样例与质量边界

Apple M1 CPU、同一模型实例连续推理，单次样例，不是手机基准或性能保证。

| 模型 | 样例 | 输出 | 推理时间 |
| --- | --- | --- | --- |
| 腾讯 | The launch made the impossible look routine. | 这次发射让原本不可能的事情变得平常了。 | 1,001 ms |
| 腾讯 | 今日は雨なので、傘を忘れないでください。 | 今天下雨，请别忘了带伞。 | 1,356 ms |
| 腾讯 | It needs more work before release.（含上级上下文） | 在发布前它需要做更多的工作。 | 1,567 ms |
| OPUS | The launch made the impossible look routine. | 发射使不可能的外表变得例行。 | 54 ms |
| OPUS | 今日は雨なので、傘を忘れないでください。 | 今天下雨了,请别忘了你的伞 | 233 ms，含日语模型首次加载 |

腾讯首次加载 506 ms。OPUS beam=2 对照没有修复关键反讽/省略句错误，且更慢，因此使用 beam=1 和逐 token 取消。OPUS 对“それはさすがに無理じゃない？”、“Yeah, that aged well.”的翻译不合格；模型可选不代表复杂语义已验收。模型质量提升空间仍存在。

## 未完成的实机验收与已知风险

- ML Kit 仅完成 SDK 依赖解析、编译和打包，未在 Android 运行推理、首次下载或测量内存。需要能访问 Google 的模型下载服务。
- 未实测正常覆盖安装、X 的完整评论/私信页面、两分钟实际内存曲线、前后台来回切换、Google 标识的位置与遮挡。
- Compose 过期订阅依据读取活跃性判断，不能等同于严格屏幕可见区域判定；需要快速滚动实测。
- 不承诺所有帖子两秒内完成。冷启动、长文本、低端手机、后台限制及网络模型下载均影响体验。
- 既有视频下载后续回调失联可能导致按钮忙碌、手势取消序列边界及外部下载 Activity 调用者约束，仍是后续审查项；本版没有声称完成这些路径的实机修复。

## 用户验证顺序

直接覆盖安装，重启 X；打开“翻译方式”，检查旧腾讯模型显示已就绪。逐个选择、下载并测试引擎。进入 X 查看英日帖子与评论，切后台 1 分钟后返回，再切后台超过 2 分钟后返回，对比加载感受。切换引擎后旧译文不应覆盖新结果；本地与原生始终互斥。
