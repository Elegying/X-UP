# X-UP 1.8.0-beta4 审查记录

2026-10-08；版本号 23；LSPosed API 102；适配 X 12.31.0-prod.01 / 312310001。本轮未操作手机。

## 范围与实现

新增“阅读与翻译 → 去广告”，默认开启，沿用现有独立开关持久化、LSPosed 同步和恢复逻辑。

通过已提取 X APK 核对以下模型结构：

- com.x.models.timelines.items.j1.e：推广帖元数据。
- com.x.models.timelines.items.b2.h：推广用户元数据。
- com.x.models.timelines.items.y1.a → com.x.models.sf.j：推广趋势元数据。
- com.x.models.timelines.items.p1：专用图片广告条目。
- com.x.models.timelines.items.a1.a / d1.a：模块及子条目，按需复制修改分支，保留其余字段。

过滤点为 com.x.urt.ui.b.f 的第一个不可变列表参数，已核对其 26 个参数、第 22 下标的 Composer 和后续变化标志；该入口把条目交给统一时间线布局。只替换展示副本，不改原列表、数据库、网络响应和广告元数据。使用 X 的原生不可变集合构造过滤结果，每个过滤后的空列表也保有独立身份，避免多个全广告页面恢复时串页；保留正常条目的身份、顺序、键与游标。全广告模块删除，混合模块只删除广告子项，原本空模块保留。递归上限 12，未知类型保留；适配异常保留原时间线。

通过 Compose 状态订阅开关变化，促使活动页面重新读取过滤列表。过滤副本保留弱身份映射，可从 Compose 捕获的过滤副本恢复原始列表；仅缓存最近 8 个弱引用结果，避免每次重组扫描整页。原始数据没有被永久删除。

## 未完成的实机验证

主入口覆盖的是统一 URT 时间线，不宣称所有 X 页面均无广告；视频贴片、独立广告页和其他特殊广告入口尚未覆盖。过滤发生在展示层，不拦截下载请求，也不承诺省流量。

尚未实测首页、评论、搜索与列表页面的实际广告样本、开关重绘、快速滚动和分页。设备验收应观察移除条目后是否存在空隙、滚动位置跳变或加载更多异常；关闭开关应恢复当前保留的原始列表。无法识别的条目保留，不按“广告”“推广”等正文文字猜测。
