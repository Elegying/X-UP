# X-UP 1.8.0-beta5 实机审查

2026-10-08；版本号 24；LSPosed API 102；手机 2509FPN0BC；X 12.31.0-prod.01 / 312310001。

## 根因与复现

手机当前时间线出现的符号是 U+2047「⁇」，不是字体缺字或 JNI 的 UTF-8 损坏。关闭本地翻译还原同一条公开帖子后，确认异常段落实际为中文夹单个拉丁字母。旧版筛选把任何非汉字字母都视为待翻译内容，小模型又只按有无日语假名选择日语或英语，因此整段中文被送进英语模型。SentencePiece / CT2 的未知词最后被解码成「⁇」。整篇原有汉字使旧的全文校验仍然通过，错误输出可进入缓存。

使用独立、同签名的临时 instrumentation，加载手机已安装模块中的真实引擎类、JNI 与已下载模型。每个引擎采用相同的 12 组人工样例，共 36 组；未使用私信作测试数据，未添加生产调试入口。测试后已卸载测试包。

| 样例 | beta4 OPUS | beta4 ML Kit | beta4 腾讯 |
| --- | --- | --- | --- |
| 中文夹单个 B、表情 | 输出「⁇, ⁇, ⁇」 | 擅自改变 B 的大小写 | 没有未知字符，仍有措辞改写 |
| 韩语、阿拉伯语、俄语 | 未知字符或连续问号 | 原文被错误重排、空格消失 | 样例可生成中文，无同样符号问题 |
| 英语与日语表情 | 表情丢失 | 表情丢失或变成 ♥ | 样例表情保留 |
| 英日混合两句 | 英语也经过日译英中转 | 同样错误选择日语源语言 | 样例无此路由问题 |

JNI 已使用标准 UTF-8 字节数组；本次保留该机制。腾讯未复现同类未知字符问题，不代表所有内容质量都已保证。

## 修复

- 新增独立小模型路由策略，按句判断英语和日语；中文夹拉丁字母、不支持的文字脚本、无假名的汉字混合句保留原文。
- 保留普通表情、肤色、ZWJ 组合表情、旗帜和键帽；模型不再改写这些符号。
- OPUS 分词输入与输出拒绝未知词，包含日英中转阶段。所有引擎共用输出保护；小模型单句写缓存前检查新增未知字符、只有标点的结果与明显重复输出。正常问句和原有问号保留。
- 英语句子不再因为另一句出现日语而额外经过日译英。
- 用户模型 i8 / d5 及私信社交用户模型 x7 的身份字段单独保护。Compose 与 TextView 都跳过已识别用户名、昵称；@账号仍由原有锚点保护。索引只在内存保留最多 2048 项，精确匹配，不按姓名子串删改正文。
- 数字及 K/M/B 浏览、点赞计数不作为英语正文翻译。
- 模型目录、引擎选择、下载协议和后台两分钟缓冲不变。

## 修复后证据

- 在 X 搜索中重新找到最初出现问题的同一公开帖子：异常段落已完整保留原文和表情，不再出现「⁇」，浏览量保持 `20K`。
- X 个人资料页、帖子署名及评论作者昵称保持原文，例如 `Elon Musk`、`Chakri Goud Motapothula`、`Ales Jon`；评论英语正文仍能自动译成中文。LSPosed 记录 identityText READY 与 globalTextTranslation READY。
- 最终 APK 再跑 36 组对照：OPUS 的不支持脚本与中文混合输入直接保留；ML Kit 的相关字符和表情保留；腾讯本组未输出未知字符。OPUS 的 `Good morning` 仍能触发模型重复输出，现在被明确拒绝，界面保留原文，不将重复译文缓存。35 组返回正常结果或保留原文，1 组为预期的质量保护拒绝。
- 代表性短句、模型对象创建后的引擎调用：OPUS 英语约 16–36 ms、日语约 76 ms；ML Kit 英语约 0–8 ms（含片段缓存命中）、日语约 20 ms；腾讯约 675–1504 ms。小模型含日英两句首次路径分别约 527 / 246 ms。这些不是打开帖子端到端延迟，也不包含完整冷启动时间。
- 覆盖安装前后腾讯与 OPUS 模型文件大小列表一致；腾讯及 OPUS 全部 10 个文件 SHA-256 与固定清单一致。ML Kit 已下载模型直接通过真实推理，未触发重下载。
- 用户设置恢复为 OPUS、本地翻译开启、X 原生翻译关闭；原快进 5 秒设置保留。

## 边界

小模型的语义能力没有因这些保护变成大模型：OPUS 仍可能错译日语、俚语和省略表达；异常时保留原文，不假装已翻译。当前脚本路由不是完整语言识别器，不能保证识别所有使用拉丁字母的其他语言。包含汉字而无假名的混合句采取保守保留，可能减少部分可译句覆盖率。身份索引精确匹配也会保守跳过与已知昵称完全相同的短正文；特殊页面若采用未覆盖的身份模型仍需补充适配。此次验证覆盖个人资料、公开帖子、评论与搜索，不包含所有私信和特殊自绘页面。未对其他视频、下载、去广告功能进行新的完整实机回归。
