# X-UP 1.8.0-beta7 在线更新审查

2026-10-08；版本号 26；适配 X 12.31.0-prod.01；API 102。

## 功能与边界

入口为“模块 → 检查更新”。进入页面或点击按钮时请求项目 GitHub Releases，显示当前版本、候选版本、附件大小和更新说明。测试版渠道可关闭；不做后台定时检查、不静默安装、不自动降级。

网络、版本政策、下载校验、APK 只读共享与页面分别实现。版本按数字比较，正式版高于同版本 rc/beta/alpha，忽略模型资源标签和草稿。缺少 APK 或 SHA-256 的最新版本会提示附件尚未就绪，不伪装成“没有更新”。

下载交给 Android DownloadManager，记录任务 ID 与候选版本，支持系统网络等待、取消、重试；计费网络在开始前提醒。页面后台时不轮询，下载完成或取消后也停止轮询。

完整性、包名、versionName、递增 versionCode 与当前签名集合校验通过后，复制至内部缓存，通过不导出的只读 Provider 临时授权系统安装器。每次安装前重新校验，Provider 不暴露任意文件路径。系统安装器通过 MATCH_SYSTEM_ONLY + APK intent 查询并显式指定，避免用户默认 APK 打开工具接管。

beta6 曾沿用通用 APK 打开方式，实机被第三方工具接管；beta7 已改为明确调用系统安装器。

## 实机结果

设备 2509FPN0BC；测试仅涉及 X-UP、其 APK 下载目录和系统安装界面，未删除模型或用户配置。

为验证首次提供更新功能的版本，先给手机安装同签名的过渡测试构建：更新逻辑与 beta7 一致，仅保持 beta5 的版本标识。它不是公开发布资产。最终 beta7 通过插件检查正式 GitHub 发布记录、下载、校验并交给系统安装器完成，最终版本未通过 ADB 代装。

- 开启测试版渠道能发现 beta7；关闭后不提供测试版更新，再开启可恢复发现。
- 手机从公开发布地址下载真实 APK，展示“已校验，可安装”。后台下载时文件实际达到完整大小。
- 在测试专用的更新 APK 末尾增加一个字节后，安装前重新校验明确报“安装包大小不匹配”，阻止进入安装器；取消清理与重新下载可用。
- 无 URI 授权的 shell 查询安装包 Provider 收到 SecurityException，不能读取内部文件。
- 首次按 Android 设置流程允许 X-UP 安装应用；最终窗口为 com.miui.packageinstaller，而非第三方工具。
- 小米安装器的联网扫描不可用；使用其“单次安装授权”完成本次已验证安装包的升级，未关闭系统全局安全功能。
- 安装器显示 beta5 → beta7、来源 X-UP；安装后 PackageManager 确认 versionCode=26、versionName=1.8.0-beta7、installerPackageName=com.miui.packageinstaller。
- 重新启动模块后显示当前 beta7、当前已是所选渠道最新版本。
- 腾讯、ML Kit、OPUS 均仍显示已下载，腾讯与 OPUS 安装前后文件大小清单一致。OPUS 选择、本地翻译开启、原生翻译关闭和 5 秒快进设置保留。
- 已安装 APK、公开匿名下载 APK与本地发布 APK 字节哈希一致：`a2f90b0f75bc1fa2b73f847844faff17ffbba06dd82f3d8c7f0a87c4fafd852e`。

## 尚未覆盖

本轮没有模拟实际移动流量计费，也未覆盖所有厂商安装器、设备重启或进程被强制终止后的恢复。后台下载已观察到完成，但返回页面期间存在取消交互，未将该轮页面恢复计为独立通过。正常下载、校验、安装和安装后无更新路径已实测。GitHub 被阻断、限流、系统下载服务关闭、空间不足等场景仍可能失败；页面保留重试和发布页入口，不承诺所有网络可达。其他视频、翻译、去广告功能本次未做完整实机回归。
