# X-UP 1.8.0-beta8 审查与发布说明

2026-10-10；版本号 27；适配 X 12.31.0-prod.01；现代 Xposed API 102。

## 默认翻译

Google ML Kit 成为默认本地翻译引擎。新安装、缺少引擎设置或保存值无效时，模块设置、X 端偏好读取及模型下载入口使用同一默认值。默认值集中在 `LocalEngine.DEFAULT`，已保存的腾讯、Google、OPUS 标识保持兼容。

覆盖安装保留已保存的引擎选择和已有模型。已有用户如需切换 Google，在“翻译方式”中选择一次即可。首次使用仍需在模型页下载中文和日语语言包；下载完成前保留原文。默认变更不自动下载模型，也不发送正文到在线翻译接口。Google 不使用帖子上下文提示词，日译中经英语中转。

## 随版修复

- 下载入口增加可信调用者签发的一次性任务凭据，阻止裸 URL 启动；任务状态可恢复和查询。
- 视频下载可从图标、下载设置页和通知取消，处理进程中断、旧任务取消及相册文件清理边界。
- 修复横屏手势起点范围、窗口坐标偏移与异常复位后的触摸流处理，保留原右侧双击和下半区双击。
- 暂停模型下载时保留有效分片，旧的 Google 语言包查询不再覆盖新的下载状态。
- 总翻译开关保存后通知本地任务调度，取消无效任务、清理队列并安排引擎释放。
- 构建使用 Java 17 字节码级别；增加 Android 主机回归、JUnit、Lint 与双 ABI Debug 构建工作流，覆盖 PR、main 和版本标签。

完整根因、修复前失败和边界说明见 [全项目审查](project-audit-2026-10-10.md)。

## 验证与产物

默认值回归运行真实 `SettingsStore` 和 `RemoteSettings`，覆盖新安装、无效设置，以及三个引擎分别保存在本地或远端的升级情形；同时验证本地/原生翻译互斥。Android 存储、框架桥接和推理引擎使用受控替身。

发布流程执行 `bash test.sh`、`testDebugUnitTest`、`lintRelease`、完整 Debug/Release 构建，检查原签名兼容、APK 版本和 16KB 对齐，再通过受保护 PR 合并与版本标签检查。公开附件包含同签名 APK、准确标签对应的源码 ZIP、SHA-256 清单和本说明。发布后独立下载公开附件，并用生产更新解析器核对从 beta7 能发现 beta8。

本版本没有连接 Android 设备，不能把主机回归、构建或公开下载当作实机安装、模型下载、翻译质量和所有 X 页面验收。升级后需重新启动 X。Google 下载服务不可达时保留原文和手动重试入口。
