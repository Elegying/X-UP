# X-UP 1.8.0-beta9 审查与发布说明

2026-10-10；版本号 28；适配 X 12.31.0-prod.01；现代 Xposed API 102。

## X 页面提示

原 `GoogleAttribution` 在 Google 本地翻译启用时，把 `powered by Google Translate` 图片添加到 X 的 Activity 窗口右下角。前台恢复或译文刷新均可能触发这层提示。

本版移除该悬浮视图实现及其在 `GlobalTextTranslationHook` 中的创建、刷新和清理调用，并移除仅供该视图使用的 Activity 引用。文字翻译、前后台状态通知、任务取消和译文刷新路径继续使用原实现。模块模型测试页的 Google 标识和第三方来源说明仍可查看。

安装新版后需重新启动 X，已运行进程不会自动替换旧 Hook。

## 默认引擎与审查修复

Google ML Kit 为默认本地翻译引擎。新安装、缺少或无效引擎配置使用 Google；覆盖升级保留有效的已选引擎与下载模型。首次使用仍需在模型页下载语言包。

本版包含 [beta8 审查说明](1.8.0-beta8-review.md) 所列的设置、模型下载、视频下载、手势及构建修复。beta8 已完成独立验证并固定标签，因本次新增界面调整，公开交付版本顺延为 beta9。

## 验证范围

执行已有主机回归、JUnit、Lint 和完整 Debug/Release 构建，并核对签名、包名、版本、16KB 对齐、最终标签源码与公开附件。移除悬浮图片属于范围明确的界面调整，不新增仅断言实现细节的测试。

本次未连接 Android 设备，构建和静态证据不能替代 X 页面实机截图、模型下载或翻译质量验证。
