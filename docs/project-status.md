# X-UP 项目现状与后续计划

更新于 2026-11-16。当前基线为测试版 1.8.0-beta13（versionCode 32）。

## 项目目标

- 在 Android 上通过 LSPosed 增强 X 的日常使用，覆盖视频手势与保存、本地中文翻译、最新评论和时间线推广内容过滤。
- 支持用户保留 X 自动更新。能够识别的结构变动由模块自动适配，个别功能失配时尽量保留 X 原有行为和其他增强功能。
- 支持同签名覆盖升级，保留设置和已下载模型。在模块内提供兼容状态、重扫和更新入口。

## 已确定的方案

| 范围 | 方案 |
| --- | --- |
| 运行环境 | Android 11 及以上、Root、支持现代 Xposed API 102 的 LSPosed。各项功能可在模块设置中控制，设置通过 LSPosed 服务同步。 |
| 兼容策略 | 按业务特征、类型和调用关系匹配入口，按功能缓存当前 X 安装包的匹配结果。遇到由缓存引发的结构错误时，仅对受影响功能清除缓存并重试一次。候选歧义时停止匹配，重大结构变化由新版模块适配。 |
| 异常恢复 | 同一 Hook 入口累计三个回调异常后，在本进程放行原调用。“状态与帮助”显示匹配路径和故障原因，可请求下次启动时完整重扫，并复制不含帖子和账号的报告。 |
| 翻译与模型 | Google ML Kit 为默认本地引擎，可切换腾讯 HY-MT2 或 OPUS-MT。模型单独下载。本地翻译与 X 原生联网翻译互斥。 |
| 发布与更新 | 通过 GitHub Releases 提供 APK 和 SHA-256 清单。模块校验摘要、包名、版本及签名后交给系统安装器，由用户确认。 |

## 当前进度

- **版本**。beta13 已合入，项目发布记录将其标为 GitHub Release 测试版。它包含 beta12 的 X 12.42 适配，以及按功能缓存恢复、运行异常保护、诊断和手动重扫。beta12 仅用于本地测试。相关记录见 [更新日志](../CHANGELOG.md) 和 [beta13 验收记录](1.8.0-beta13-review.md)。
- **构建与回归**。beta13 记录 897 条主机断言和边界检查通过、148 项 JUnit 通过，Release Lint 为 0 错误、46 警告。ARM64/x86_64 Release 构建、签名核对和 16 KB 对齐检查通过。
- **实机**。Xiaomi 17 Pro Max（Android 17、X 12.42.0-prod.01）同签名覆盖安装后，11/11 项兼容检测正常。已验证缓存损坏后的单项恢复、手动完整重扫和下半区双击加连续点按。视频列表显示中文翻译，下载按钮可见。beta12 的视频保存等实测另见 [beta12 验收记录](1.8.0-beta12-review.md)。
- **验收缺口**。beta13 尚缺真实广告开关对照、三种引擎的完整复测、私信布局和长时间播放验证。运行回退已通过主机故障注入，实机的真实回调异常和跨 X 版本升级仍待验证。

## 接下来要做什么

以下优先级按现有验收缺口整理，供后续排期。

1. **补齐 beta13 实机回归**。记录设备、X 版本和测试结果。覆盖真实推广内容的开关对照、三引擎下载和英日翻译、私信文字显示、完整视频保存及长时间播放。
2. **验证下一次 X 升级**。有更新样本时，记录升级前后的检测结果，确认 X 更新后重新扫描、失配时保留原行为以及状态页报告与实际表现一致。若出现失配，先根据报告定位功能，再决定是否需要兼容修复。
3. **跟进仍有风险的维护项**。按影响检查 46 条 Lint 警告；结合后续失配记录评估视频下载和手势共享依赖造成的影响。修复后的回归和发布证据写入对应版本验收记录。

维护此页时更新版本、验证范围和剩余事项。构建和签名恢复步骤见 [构建与签名恢复说明](build-recovery.md)。
